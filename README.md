## 🤖 Production Automation Systems & AI Applications

### 1. 🚀 [ProAlign AI — WhatsApp Career Platform](https://github.com/Olusam-id/proalign-bot)
> **AI Engine | WhatsApp Native | Document Transformation Pipeline**

A WhatsApp-native career tools platform that accepts candidate CVs (PDF) and job posting text or URLs, returning an ATS-optimized tailored CV and an editable `.docx` cover letter in under **90 seconds**.

- **Core Innovations:**
  - Integrated **Anthropic Claude AI** for context-aware resume alignment and personalized cover letter generation.
  - Developed an automated job posting web scraper and a memory-sensitive **Puppeteer rendering queue** for document generation.
  - Engineered document conversion engines (**PDF, DOCX, PPTX, XLSX**) backed by **Supabase (Postgres)** and **Paystack** subscription workflows.
- **Tech Stack:** `Node.js` `TypeScript` `Twilio WhatsApp API` `Anthropic Claude` `Puppeteer` `Supabase` `Paystack` `Railway`

### 2. 💬 [Configurable WhatsApp Operations & Report Bot](https://github.com/Olusam-id/whatsapp-report-bot)
> **Enterprise Operations | Schema Parsing | Real-time Data Pipeline**

A multi-tenant WhatsApp automation service that monitors operational group chats, detects structured trigger phrases (`#REPORT`, `#INCIDENT`), validates incoming fields, and forwards clean JSON payloads to external systems.

- **Core Innovations:**
  - Designed a **schema-driven parsing architecture** allowing custom field rules (dates, amounts, required inputs) without code changes.
  - Implemented **retry-aware webhook delivery**, duplicate-message deduplication, and runtime configuration reloading.
  - Created a companion **Google Apps Script endpoint** to log incoming reports directly into Google Sheets.
- **Tech Stack:** `Node.js` `WhatsApp Web API` `Webhooks` `Google Apps Script` `Docker` `Kubernetes`

## 📊 Business Intelligence & Analytics Projects

### 3. ☕ The Daily Grind Coffee — Profit Margin & Pricing Strategy Analysis
> **Retail Analytics | Margin Recovery | Pricing Strategy** | **Tools:** `SQL` `Power BI` `DAX`

Conducted an analysis of order data following profit margin erosion caused by rising COGS and tariffs.
- Extracted and transformed multi-year order data using SQL, connected directly to Power BI.
- Identified a **4.2% margin decline** (56.64% down to 52.43%) across the product portfolio.
- Flagged six products below the critical 30% Gross Margin threshold (e.g., Chemex Filters, Logo Hoodie below 12%).
- Delivered actionable tiered pricing strategies: price adjustments, discontinuation targets, and high-margin anchors.

| Portfolio KPI | Metric Value |
|---|---|
| **Total Revenue** | $871.07K |
| **Gross Profit** | $473.43K |
| **COGS** | $393.36K |
| **Blended Gross Margin** | 54.84% |
